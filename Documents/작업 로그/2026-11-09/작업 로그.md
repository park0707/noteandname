## [작업] 집필실 복선 관리 드롭다운에 '복선 목록' 신규 추가 및 인라인 편집/화수 연장/삭제 모달 구현

### 1. 지시 사항 (User Request)
- "집필실에 복선 관리 항목에 복선 설치, 복선 회수 항목만 있는 데 복선 항목 리스트 따로 만든 뒤 현재 설치된 복선 리스트를 볼 수 있게 하고 만들어 진 복선 중에 회수 화수를 늘리거나 이름을 바꾸거나 삭제하거나 이런 수저이 가능하게 해줘"

### 2. 목적 및 배경 (Purpose & Context)
- 기존 집필실 에디터 상단 툴바의 복선 관리 드롭다운 메뉴에는 [복선 설치], [복선 회수] 2개 항목만 제공되어, 설치된 복선 전체 현황을 한눈에 조회하거나 회수 화수 연장, 복선 이름 변경, 삭제 등의 수정 작업을 진행할 수 없었음.
- 작가가 집필 도중 전체 복선 목록을 직관적으로 확인하고, 스토리 전개 변경에 따라 회수 목표 회차를 늘리거나 복선명을 수정하고 삭제할 수 있는 독립 모달(`ForeshadowingListModal`)을 구축하여 복선 관리 워크플로우를 완성함.

### 3. 수정 대상 및 규모 (Scope & Impact)
- `src/components/workspace/writingspace/Modals/ForeshadowingListModal.tsx` (신규 생성, 약 480라인):
  - 전체 복선 리스트 조회 모달 컴포넌트
  - 탭 필터(전체, 미회수, 회수 완료) 및 실시간 검색, 정렬(목표 회차순, 설치 회차순, 최근 등록순) 기능
  - 빠른 목표 화수 연장 기능 (+1화, +5화, +10화, +20화 원클릭 버튼)
  - 인라인 상세 편집 모드 (복선명, 설치 회차, 목표 회차, 상세 단서 및 메모 수정)
  - 복선 삭제 기능 (`useAlertConfirm` 컨펌 연동)
  - 복선 회수/미회수 상태 토글 기능
  - [+ 새 복선 설치] 모달 연계 버튼 제공
- `src/components/workspace/writingspace/EditorToolbar.tsx` (+30라인):
  - 복선 관리 드롭다운에 `복선 목록` 메뉴 항목 추가
  - `showForeshadowingListModal` 상태 관리 및 `ForeshadowingListModal` 렌더링 연결
  - 복선 수정(`onUpdateForeshadowing`), 삭제(`onDeleteForeshadowing`), 상태 토글(`onToggleResolve`), 새 복선 모달 전환(`onOpenPlantModal`) 핸들러 연동

### 4. 세부 구현 내용 (Implementation Details)
- **UI 일관성 및 테마 동기화**: 기존 `ResolveForeshadowingModal`, `PlantForeshadowingModal`과 동일한 다크/라이트 테마 스타일 규격(`rounded-2xl`, 테두리, 그림자, 스크롤바 디자인) 적용.
- **원스톱 복선 수정 경험**:
  - 카드마다 [수정(연필)] 버튼을 누르면 인라인 에디팅 폼으로 즉시 전환되어 복선 이름, 설치 회차, 목표 회수 회차, 단서 내용을 정밀 수정 가능.
  - 미회수 복선 카드의 경우 하단에 `+1화`, `+5화`, `+10화`, `+20화` 빠른 화수 연장 버튼을 두어 집필 흐름을 끊지 않고 원클릭으로 목표 회차를 즉시 연장할 수 있도록 편의 제공.
  - [삭제(휴지통)] 버튼 클릭 시 확인 컨펌 창을 띄워 오작동으로 인한 데이터 유실을 방지.
- **기존 사용자 코드 100% 보존**: 사용자가 `PlantForeshadowingModal.tsx`에서 헤더 테두리 클래스를 조정한 부분 등을 일절 훼손하지 않고 온전히 보존.

### 5. 실수 방지 및 기술 주의사항 (Lessons & Anti-Patterns)
- `setForeshadowings` 상태 갱신 시 함수형 업데이트(`prev => prev.map(...)` 및 `prev => prev.filter(...)`)를 적용하여 동시성 레이스 컨디션 및 불변성 오류를 방지함.
- `Foreshadowing` 인터페이스에 정의된 프로퍼티 규격을 엄격히 준수하고, 기존 호출부 인터페이스에 파괴적 변경(Breaking Change)을 가하지 않음.

## [작업] 복선 목록 관리 모달 검색 바 좌측 여백(Padding) 보정 및 검색창 정렬 개선

### 1. 지시 사항 (User Request)
- "제공된 이미지가 복선 목록 관리의 검색 창인데 검색 아이콘이 검색 바 왼쪽에 여백 없이 붙어 있어서 보기 불편하다, 약간의 여백을 추가해줘"

### 2. 목적 및 배경 (Purpose & Context)
- `ForeshadowingListModal.tsx`의 검색 바 래퍼에 `rounded-xl` 모서리 곡률이 적용되어 있었으나, 아이콘 좌측 패딩이 부족하여 돋보기 아이콘이 둥근 좌측 경계선에 너무 가깝게 붙어 시각적 답답함을 유발함.

### 3. 수정 대상 및 규모 (Scope & Impact)
- `src/components/workspace/writingspace/Modals/ForeshadowingListModal.tsx` (+6 / -4 라인):
  - 검색 컨테이너 래퍼에 `pl-3.5 pr-2 py-1.5` 패딩 및 `sm:w-60` 너비 적용
  - 검색 아이콘 우측 마진 `mr-2` 설정 및 인풋의 텍스트 영역 정렬 최적화
  - 헤더 우측 [새 복선 설치] 및 닫기 버튼 렌더링 블록 정돈

### 4. 세부 구현 내용 (Implementation Details)
- 컨테이너 좌측 내부 여백(`pl-3.5`, 14px)을 부여하여 모달의 둥근 모서리 곡률 안쪽으로 돋보기 아이콘이 안정적이고 넉넉하게 배치되도록 개선함.
- 인풋 텍스트와 돋보기 사이 간격(`mr-2`)을 일정하게 유지하고 검색어 초기화(X) 버튼 여백도 함께 조율함.

### 5. 실수 방지 및 기술 주의사항 (Lessons & Anti-Patterns)
- 아이콘 자체에만 `ml`을 주는 방식보다 컨테이너에 `pl-3.5` 패딩을 명시하여 브라우저 리사이징 및 폰트 렌더링 차이에서도 둥근 모서리와의 일정한 여백을 보장함.

- TypeScript 컴파일 검사: `tsc --noEmit` 0 errors 통과
- Linter 검사: `npm run lint` (`oxlint`) 신규/수정 파일 경고 0건 통과
