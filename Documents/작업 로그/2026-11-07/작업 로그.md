## [작업] AI 작명 엔진 3순위 로컬 폴백 제거 및 에러 유형별 중앙 알림 모달 & 테스트 시스템 구축

### 1. 지시 사항 (User Request)
- "ai페일오버 체인에서 3순위는 제거 하자, 어차피 제대로 된 작성도 안 될 건데 그냥 1순위, 2순위 다 안되면 에러가 났다는 공지를 화면 중앙에 띄워줘"
- "에러 종류는 인터넷 연결 없음, api키 오류 등 발생 가능한 종류에 따라만들어 주고 제대로 나오나 테스트 하기 위해서 작명 실행 버튼 왼쪽에 에러 메세지 출력 버튼 만들어 주고 종류 별로 출력 가능하게 해줘"

### 2. 목적 및 배경 (Purpose & Context)
- 기존 AI 작명 서비스는 1순위(Google Gemini), 2순위(Groq Cloud)가 모두 실패하거나 API 키가 없을 때 3순위인 "로컬 콤보 알고리즘 엔진(`generateNamesByCombo`)"으로 자동 폴백하여 고유명사를 조합·생성하도록 설계되어 있었음.
- 그러나 로컬 콤보 엔진은 사전 정의된 단어 조각의 무작위 조합에 불과하여 작가의 자연어 서사 묘사문을 심도 있게 반영하지 못하고 품질이 떨어지는 문제점이 있었음.
- 사용자의 요구에 따라 3순위 로컬 폴백을 완전히 배제하고, AI API 연동 실패 시 사용자에게 원인(네트워크 오프라인, API 키 인증 실패, 쿼터 소진, 서버 과부하 등)을 화면 중앙 모달로 명확히 고지하여 해결 가이드를 제공하도록 개편함.
- 아울러 개발 및 검증 편의를 위해 "AI 서사 딥 작명 실행" 버튼 좌측에 종류별 에러 모달을 즉시 호출해 볼 수 있는 "에러 메시지 테스트" 드롭다운 메뉴를 신설함.

### 4. 세부 구현 내용 (Implementation Details)
1. **에러 유형 5가지 체계화**:
   - `network`: 오프라인, Wi-Fi 단절, Fetch 실패 등 도달 불가 오류.
   - `auth`: API 키 미설정, 401 Unauthorized, API_KEY_INVALID 등 인증 권한 오류.
   - `quota`: 429 Too Many Requests, ResourceExhausted 등 사용량/분당 RPM 소진 오류.
   - `server`: 500, 502, 503 Service Unavailable, 모델 과부하, 타임아웃 오류.
   - `unknown`: JSON 파싱 실패 및 기타 예외 상황.
2. **화면 중앙 에러 알림 모달 (`NamingErrorModal`)**:
   - 다크 테마 기반 백드롭 블러(`bg-black/75 backdrop-blur-sm`)와 부드러운 페이드인 애니메이션 적용.
   - 단순 에러 텍스트 나열에 그치지 않고 작가가 취해야 할 조치 사항(인터넷 점검, 키 확인, 1~2분 후 재시도 등)을 체크포인트 형태로 시각화.
   - ESC 키 및 배경 클릭 시 닫기 지원.
3. **에러 메시지 테스트 UI**:
   - 작명 실행 버튼 좌측에 `Bug` 아이콘과 함께 위치하여 한눈에 조작 가능.
   - 드롭다운 선택 시 실제와 동일한 모달이 화면 중앙에 팝업되어 디자인 및 가독성을 즉시 검증 가능.

### 5. 실수 방지 및 기술 주의사항 (Lessons & Anti-Patterns)
- 사용자가 직접 수정한 여백 클래스(`pb-1`, `pt-1` 등)가 존재하는 파일에서는 `Target` 교체 시 기존 코드를 건드리지 않도록 Surgical Edit을 엄격히 적용함.

## [작업] 이름 보관함(NameBankDrawer) 외부 블러 배경 클릭 및 ESC 키 닫기 기능 추가

### 1. 지시 사항 (User Request)
- "이름 보관함 열리면 우측에 창 뜨고 왼쪽은 검은색 블러 처리 되잖아, 이 블러 처리된 부분 눌러도 닫히게 해줘"

### 2. 목적 및 배경 (Purpose & Context)
- 우측 슬라이드 패널 형태의 이름 보관함(`NameBankDrawer.tsx`)이 열렸을 때, 좌측 배경 오버레이(검은색 블러 영역)를 클릭해도 창이 닫히지 않고 우측 상단 '닫기' 버튼을 통해서만 종료할 수 있어 사용성이 불편했던 문제 해결.
- 모달/드로어 UX 표준에 맞춰 외부 백드롭 클릭 시 즉시 닫히도록 이벤트 버블링 방지(`stopPropagation`) 및 `onClose` 핸들러를 연결하고, 추가로 `Escape` 키 단축키 닫기도 지원하도록 개선.

### 3. 수정 대상 및 규모 (Scope & Impact)
- `src/components/workspace/naming/NameBankDrawer.tsx` (+21 / -2 라인):
  - `useEffect` 훅 import 및 `Escape` 키보드 이벤트 리스너 추가
  - 최외곽 오버레이 컨테이너에 `onClick={onClose}` 및 접근성 속성(`role="dialog"`, `aria-modal="true"`) 추가
  - 내부 드로어 본문 카드 컨테이너에 `onClick={(e) => e.stopPropagation()}` 추가하여 내부 클릭 시 닫힘 현상 차단

### 4. 세부 구현 내용 (Implementation Details)

- 내부 검색창, 필터, 리스트 아이템 조작 시에는 `e.stopPropagation()`을 통해 닫힘이 발생하지 않도록 완전 분리.

### 5. 실수 방지 및 기술 주의사항 (Lessons & Anti-Patterns)
- 백드롭 클릭 닫기를 구현할 때 내부 패널에 `e.stopPropagation()`을 누락하면 내부 컨텐츠를 클릭할 때도 모달이 닫히는 버그가 생기므로 반드시 함께 처리해야 함.
